Organiser les mesures

Le nuage a un nombre variable de points. Les piliers rassemblent les mesures d’une même cellule ; le PFN en construit une description de 32 valeurs, puis le scatter range chaque description dans la grille.

Le PFN transforme des caractéristiques, pas des points en objets. Le scatter ne mélange pas les voisins.

Mettre les cellules en contexte

Les fragments d’un objet peuvent couvrir plusieurs piliers. Le bloc dilaté actuel combine leurs descriptions en conservant la grille. Deux blocs résiduels appliquent quatre convolutions 3×3 avec les dilatations 1, 2, 2 et 4.

Le champ théorique 19×19 ne prouve pas une reconnaissance. Le futur backbone commun caméra/LiDAR reste à définir et ne se confond pas avec ce bloc.

Un détail pour comprendre

Une connexion résiduelle ajoute l’entrée d’un bloc à sa transformation. Le stride 1 conserve la résolution ; le padding égal à la dilation préserve les centres des cellules.

Lire les features pour une tâche

La head actuelle prédit les centres Car : une convolution 1×1 donne un score par cellule, une autre donne deux offsets XY. Le décodage convertit les pics et leurs offsets en coordonnées métriques.

Cette head de diagnostic est implémentée mais non entraînée. Elle ne prédit ni dimensions, ni hauteur, ni orientation : les boîtes 3D complètes restent une cible.

Un détail pour comprendre

Exemple synthétique : ligne 10, offset_x 0,25, résolution 0,20 m et x_min=0 donnent x=2,05 m. Aucun décalage supplémentaire d’un demi-pixel.
