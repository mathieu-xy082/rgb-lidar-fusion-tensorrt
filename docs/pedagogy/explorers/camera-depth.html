4. Moyenne des features : un exemple distinct

Supposons que deux pixels acceptés arrivent dans une même cellule avec les vecteurs de features [2,4] et [8,10]. Pour alléger le dessin, nous montrons deux canaux plutôt que 32. Cet exemple d’agrégation est indépendant du pixel manipulé au-dessus.

Le nombre de contributions n’est pas un nombre de mesures indépendantes. Les gradients atteignent les features acceptées ; le floor des indices BEV ne fournit pas de gradient de placement vers la profondeur. Une loss BEV sur ces features seules ne suffit donc pas à entraîner la head depth.
